# Ansökan – Team Manager, PostNord TPL

**Live:** https://bondarenkovita35-afk.github.io/postnord-team-manager/

Sökande: Vitaliia Sivakova

## Innehåll

- `index.html` – startsida med en interaktiv 3D-resa genom karriären (klicka "Hoppa över" för att gå direkt till sidan)
- `html/cv.html` – CV som PDF
- `html/personligt-brev.html` – personligt brev som PDF
- `html/diplom.html` – diplom, intyg och kursbetyg
- `pdf/` – alla dokument som visas på sajten

Ingen build behövs – öppna `index.html` direkt eller besök live-länken ovan. Fungerar på både dator och mobil.
